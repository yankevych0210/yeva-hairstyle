# Yeva Hairstyle

Website of **Yeva Hairstyle** — hairstyles, hair styling, waves and curls, and full looks with a makeup artist ("в 4 руки") by hair stylist Єва in Kremenchuk, Ukraine.

**Live:** https://yeva-hairstyle.vercel.app · **Instagram:** [@yeva.hairstyle](https://www.instagram.com/yeva.hairstyle/)

[![CI](https://github.com/yankevych0210/yeva-hairstyle/actions/workflows/ci.yml/badge.svg)](https://github.com/yankevych0210/yeva-hairstyle/actions/workflows/ci.yml)

## Overview

A mobile-first, single-page site in Ukrainian. The page is pre-rendered to static HTML at build time and hydrated with React, so all text is in the HTML for search engines and the page works before JavaScript loads.

**Sections:** hero with a video showreel, about, services, "Образ у 4 руки" (hair + makeup), works (filterable gallery with a photo/video lightbox), booking, Instagram (live feed via Behold). Prices, reviews and FAQ appear automatically once their data is filled in.

**Booking** goes through Instagram Direct. Telegram and phone buttons appear once those contacts are added.

## Tech stack

| | |
|---|---|

| Styling | Tailwind CSS 3, design tokens as CSS variables in `src/styles/main.css` |
| Fonts | Cormorant Garamond + Manrope, self-hosted via Fontsource (Cyrillic subsets) |
| Icons | lucide-react + custom brand icons |
| Media | WebP images (cwebp), HEVC + H.264 video (ffmpeg) |

## Getting started

Requires **Node.js 20.19+** (see `.nvmrc`).

```bash
npm install
npm run dev        # http://localhost:5173
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload (client-side render) |
| `npm run build` | Type-check → client build → SSR build → pre-render into `dist/` (+ `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, JSON-LD) |
| `npm run lint` | ESLint, zero warnings allowed |
| `npm run serve` | Serves `dist/` with the headers from `vercel.json` (CSP, caching, 404) — closest to production |
| `npm run preview` | Vite preview of `dist/` (without Vercel headers) |
| `npm run images` | `assets/originals/*` → `public/images/<name>-480.webp` and `-960.webp`, fixes EXIF rotation |
| `npm run videos` | `assets/originals/video/*` → `public/videos/<name>-hevc.mp4` + `-h264.mp4` (1080p, 30 fps, faststart) |
| `npm run showreel` | Builds the hero showreel from video fragments listed in `scripts/showreel.mjs` |
| `npm run brand` | Regenerates the logo, favicons, app icons and avatar in `assets/brand/` and `public/` |
| `npm run og` | Regenerates the Open Graph image `public/og.jpg` (1200×630) |
| `npm run qa` | Screenshots + checks in Chrome at 320–1440 px and landscape (needs a running `serve` or `preview`; screenshots go to the system temp folder) |
| `npm run qa:webkit` | Safari/iPhone checks in WebKit: scroll lock, lightbox, HEVC video |

`images` needs [`cwebp`](https://developers.google.com/speed/webp/download); `videos` and `showreel` need ffmpeg (`brew install ffmpeg`, or temporarily `npm i --no-save ffmpeg-static`). They are only used locally — Vercel builds from the committed, already-processed media.

## Updating content

Everything visible on the site lives in **`src/data/siteData.ts`**. Missing data is marked with `TODO` — when a value is `null` or an empty list, the related block is hidden rather than showing placeholders. See **[docs/CONTENT.md](docs/CONTENT.md)** for step-by-step instructions (prices, contacts, new photos and videos, FAQ, reviews) and **[docs/TODO.md](docs/TODO.md)** for what is still missing.

## Deployment

The site is hosted on [Vercel](https://vercel.com) and deploys automatically:

- a push to `main` publishes to production;
- any other branch or pull request gets its own preview URL;
- GitHub Actions runs `lint` and `build` on every push and pull request.

Vercel settings: framework preset **Vite**, build command `npm run build`, output directory `dist`, no environment variables.

When a custom domain is connected, update `siteUrl` in `src/data/siteData.ts` — canonical URL, Open Graph, sitemap, robots and structured data are all generated from it.

## SEO

- One `<h1>`, one `<h2>` per section, semantic landmarks; `lang="uk"`
- Title, description, canonical, `hreflang`, Open Graph and Twitter cards, geo tags (Kremenchuk)
- JSON-LD: `HairSalon`, `Person`, `WebSite`, `VideoObject` for every video; no ratings or reviews until real ones exist
- `robots.txt` and `sitemap.xml` (with image entries) generated at build time from `siteUrl`
- Verification tags for Google Search Console and Bing: set `seo.verification` in `siteData.ts`

Check with Google's [Rich Results Test](https://search.google.com/test/rich-results) and submit `https://yeva-hairstyle.vercel.app/sitemap.xml` in Search Console.

## Performance and accessibility

- Hero image preloaded with `fetchpriority="high"`; first-screen Cyrillic fonts preloaded
- Responsive WebP (`srcset`, explicit `width`/`height`, lazy loading); HEVC video for Safari, H.264 for the rest
- Hero video plays only without `prefers-reduced-motion` and Save-Data, and pauses off-screen
- Touch targets ≥ 44 px, visible focus, skip link, focus trap and Esc in dialogs, WCAG AA contrast
- Content is visible without JavaScript

## Security

`vercel.json` sets a strict Content-Security-Policy, HSTS, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy` and COOP. The only inline script is allowed by its SHA-256 hash; the build fails if the script in `index.html` changes without updating the hash.

## Browser support

Current Safari (iOS and macOS), Chrome, Edge and Firefox. Layout from 320 px, including landscape phones and iPhone safe areas.
